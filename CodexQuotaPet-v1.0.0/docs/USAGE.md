# 使用说明

左键点击角色或下方文字打开额度卡片，再次点击收起。显示 5 小时与 1 周剩余用量、北京时间重置时间和倒计时。每分钟更新，也可手动刷新；不可用或过期时显示未知，不将旧额度冒充实时数据。

拖动角色定位。右键菜单包含刷新、放大、缩小、恢复默认大小、恢复默认位置和退出。缩放范围 50%～200%，每步 10%；位置和尺寸会保留。卡片不跟随角色缩放。

切换到其他应用或最小化 Codex 时，桌宠会隐藏；返回 Codex 再出现。系统托盘也有查看、刷新、恢复位置和退出入口。

自动启动由本地聊天加载插件连接触发，不保证只打开首页就出现。首次安装后重启 Codex；手动退出桌宠后，可运行程序重新启动，或明确要求 Codex 启动额度桌宠。

同一 Windows 会话只保留一份桌宠。若旧版本仍在运行，先在托盘退出旧版，再运行新版本。关闭 Codex 不会强制关闭桌宠，它会隐藏并可供下次使用；可从托盘主动退出。

卸载插件不会自动删除独立下载包或尺寸设置。移动、删除已注册的本地发布目录可能影响后续插件更新，建议解压到固定位置。
